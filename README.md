# 🚀 Spring Boot — API REST | Parte 1

Projeto desenvolvido durante meus estudos de **Spring Boot**, acompanhando a primeira parte do curso do **Souza DEV**, onde comecei a trabalhar na criação de uma API REST utilizando Java e Spring Boot.

O objetivo deste projeto foi entender na prática como funciona a estrutura inicial de uma aplicação backend e como criar endpoints para receber e retornar informações através de requisições HTTP.

## 📚 Conteúdos estudados

Durante esta primeira parte, foram praticados conceitos como:

* Java aplicado ao desenvolvimento backend
* Spring Boot
* Estrutura de um projeto Spring Boot
* Criação de uma API REST
* Controllers
* `@RestController`
* `@RequestMapping`
* `@GetMapping`
* Requisições HTTP
* Endpoints
* Retorno de informações através da API
* Tratamento de erros
* Comunicação entre cliente e servidor
* Swagger para documentar nossa API REST

## 🛠️ Tecnologias utilizadas

* Java
* Spring Boot
* Maven
* IntelliJ IDEA

## 📁 Estrutura

O projeto foi organizado seguindo a estrutura padrão de uma aplicação Spring Boot, separando as responsabilidades da aplicação e utilizando as funcionalidades disponibilizadas pelo framework.

## 🎯 Objetivo

Este projeto faz parte da minha jornada de estudos em **Java e Spring Boot**, servindo como prática para entender como construir APIs REST e como o Spring Boot facilita o desenvolvimento de aplicações backend.

A ideia é continuar evoluindo o projeto nas próximas partes do curso, adicionando novos conceitos e funcionalidades.
